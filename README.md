## 🌟 Overview

This portfolio application serves as a unified command center showcasing end-to-end full-stack capabilities. Built around a single-viewport layout with precision L-shaped geometry, custom glassmorphism modals, and GitHub-styled markdown documentation viewers, it provides instant access to live deployments, credentials, technical stacks, and comprehensive product case studies.

---

## 🛠️ Tech Stack & Architecture

* **Frontend Framework:** Next.js 14 (App Router), React 18, TypeScript
* **Styling & UI:** Tailwind CSS, Lucide React Icons, Framer Motion
* **Component Architecture:** Portal-rendered interactive modals with dynamic single-page viewports
* **Documentation Engine:** React Markdown (`react-markdown`), GitHub Flavored Markdown (`remark-gfm`), Rehype Raw
* **Deployment & Hosting:** Vercel Edge Network

## ✨ Key Interactive Features

* **Single-Screen Desktop Layout:** Locked-viewport desktop view combining an L-shaped professional bio container and a 2x2 interactive project grid.
* **Universal 4-Button Card Grid:** Every project card features uniform access badges: `Creds` (Credentials & Test Logins), `README` (GitHub-styled markdown documentation), `Stack` (Architecture specs), and `Case Study` (Multi-page PNG product case studies).
* **Dual-View Modal System:**
  * **Compact Mode:** Quick-access modal frames for credentials and tech stacks.
  * **Expandable View Mode:** Centered document and image viewer with a fullscreen toggle (`Maximize2` / `Minimize2`) and vertical scrolling for multi-page product case studies (`Page 1 of N`).
* **Interactive Footer Contact Card:** Glass-blurred popup modal providing direct copy-to-clipboard actions and mail triggers for dual email addresses (`rajkelango.rk@gmail.com` and `rajkelango@outlook.com`).
